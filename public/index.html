 Skills

              

                Skills inject custom instructions into ARIA's system prompt.
                Same format as Claude SKILL.md files — drop a folder with a SKILL.md
                into skills/user/ to add one permanently.
              

              
Loading skills…

              

                
                
              

            

            

              
How to create a skill

              

                Create a file at skills/user/my-skill/SKILL.md with this format:


                ---
name: my-skill
description: What it does
version: 1.0
triggers: ["keyword1"]
---

Instructions ARIA follows when this skill is active.
