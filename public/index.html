 Skills

                into skills/user/ to add one permanently.
              

              
Loading skills…

              

                
                
              

            

            

              
How to create a skill

              

                Create a file at skills/user/my-skill/SKILL.md with this format:


                ---
name: my-skill
description: What it does
version: 1.0
triggers: ["keyword1"]
---

Instructions ARIA follows when this skill is active.
                
To give the skill its own tool, put a tool.js beside SKILL.md (see skills/public/music-theory):
                export const TOOL_META = { name: "mytool", desc: "What it does", args: "<input>", local: true };
export async function run(input, { dataDir }) { return "answer"; }
                ARIA can use it while the skill is on, and you can run it yourself as /mytool …. Set local: true only if it never fetches outside text.
